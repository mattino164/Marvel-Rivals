# Marvel Rivals — Interactive Hero Showcase

An interactive, fan-made Marvel Rivals website built with React. Explore the game's heroes through a dynamic interface featuring character abilities, stats, lore, and team-up powers.

## 🔗 Project Links

- **GitHub Repository:** [Marvel-Rivals](https://github.com/mattino164/Marvel-Rivals)
- **Live Demo:** *(https://marvel-rivals.vercel.app/)*

## ✨ Features

- **Interactive Hero Showcase** — Explore heroes from Marvel Rivals through a character-focused interface.
- **Hero Abilities** — Discover information about individual heroes and their abilities.
- **Character Stats** — View hero-related stats and information.
- **Hero Lore** — Explore character background information.
- **Team-Up Powers** — Discover team-up abilities and synergies.
- **Dynamic UI Animations** — Experience an animated interface designed to make browsing more engaging.

## 🛠️ Tech Stack

- **React** — Component-based UI development.
- **JavaScript** — Application logic and interactivity.
- **HTML** — Web page structure.
- **CSS** — Styling and visual presentation.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm, included with Node.js
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mattino164/Marvel-Rivals.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Marvel-Rivals/client
   ```

3. Install the project dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to view the website.

*Note: These commands assume the React application uses Vite and has its `package.json` inside the `client` folder. Adjust them if your project uses a different setup.*
